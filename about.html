FULL PYTHON / FASTAPI APPLICATION

Clone. Run. Experiment.

The public edition is a browser spectral editor. The Python backend is not hosted on this site. Run the complete lab on your own machine using Python 3.11 or 3.12:

git clone https://github.com/TrishulVani/trishul-vani-studio.git
cd trishul-vani-studio
python -m venv .venv
# Windows PowerShell:
.\.venv\Scripts\Activate.ps1
# Linux / macOS: source .venv/bin/activate
python -m pip install -r requirements-dev.txt
python -m pytest -q
python -m uvicorn app.main:app --host 127.0.0.1 --port 8000

Open http://127.0.0.1:8000 for the experiment lab and /studio.html for the Python-powered spectral workspace. The repository contains code, API documentation, CI workflows, Docker configuration and the development ledger.

Privacy & storage

In this public editor, imported audio and rendered layers are stored in IndexedDB on your device. Clearing this site’s browser data removes sessions. Export WAV and JSON recipes to keep a backup. The host serves app files; it does not receive your audio. Fonts may be requested from Google Fonts. Audio formats and resampling depend on your browser; the Python lab uses SciPy resampling. This alpha is not a validated hearing-protection or safety device.
