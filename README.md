# त्रिSHUL VANI — Public Website

## Live website

**Main website and connected backend:** [https://trishul-vani-studio.onrender.com/](https://trishul-vani-studio.onrender.com/)

The Render Studio address serves the introduction, overview dashboard, audio laboratory, Spectral Studio, and virtual hardware pages from one application. The Python API is on the same origin, so experiments and frontend workspaces stay connected.

**Version 2 / Original Edition:** [https://trishul-vani-studio.onrender.com/design-v2/](https://trishul-vani-studio.onrender.com/design-v2/)

## Source and operations

- **Application source:** [TrishulVani/trishul-vani-studio](https://github.com/TrishulVani/trishul-vani-studio)
- **Hosting:** Render web service, built from the application repository's `main` branch
- **API health:** [https://trishul-vani-studio.onrender.com/api/health](https://trishul-vani-studio.onrender.com/api/health)
- **Interactive API docs:** [https://trishul-vani-studio.onrender.com/docs](https://trishul-vani-studio.onrender.com/docs)

This repository remains as a legacy address handoff. Its root redirects visitors to the Render Studio site while preserving the requested path, query string, and fragment. GitHub Pages is not the canonical website host.

The product is a research prototype. Virtual hardware behavior is simulated; it does not prove physical device compatibility, safety, or deployment. Audio-processing claims and supported endpoints are documented in the application source repository.
