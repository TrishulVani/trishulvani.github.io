# TRISHUL VANI public website

Version 1: https://trishulvani.github.io

Version 2: https://trishulvani.github.io/design-v2/

Version 1 keeps its original sculpted mint-metal trident intro and connected application. The Version 2 alias leads to a separate, dark graphite/jade six-scene experience with a trident intro and direct access to the same real FastAPI laboratory. Both lab versions include a guided Help tour after the matching application branch is deployed. The Version 2 route intentionally navigates to the application's origin to keep visitor session cookies and audio exports reliable.

Application source, tests, Docker configuration, and documentation: https://github.com/TrishulVani/trishul-vani-studio

Backend: https://trishul-vani-studio.onrender.com

GitHub Pages publishes `main`: root serves Version 1 and `design-v2/` is the Version 2 alias. Release the application branch before merging this alias branch. No keys, credentials, audio, or datasets are stored in this repository.
